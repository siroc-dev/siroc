Documentation

Siroc is a Linux hosting panel. Hosting accounts are real system users. This page covers install, first admin, command-line password reset, and upgrades. Current version 0.2.1.

Install First admin Reset admin Check and upgrade Let's Encrypt Hosting

Install

On a fresh Ubuntu or Debian server, as root:

One-line install
curl -fsSL https://siroc.dev/install.sh | sudo bash

The panel listens on port 8443. Packages come from https://get.siroc.dev.

To install from a downloaded tarball:

From a package
tar -xzf siroc-linux-amd64.tar.gz
cd siroc
sudo ./install.sh

First admin

The installer prints a one-time setup URL. It is also saved at /var/lib/siroc/setup.url until setup completes.

Open that link, create the panel administrator, and enter a Let's Encrypt email. This admin lives in the panel database. It is not a Linux user and cannot be named as a hosting account.

Reset the admin password

If you lose the panel admin password, reset it on the server as root. Sessions for that admin are signed out.

Generate a new password
sudo siroc passwd-admin
Set a specific password
sudo siroc passwd-admin admin 'YourNewPassword'

The same command is available as sudo siroc-panel passwd-admin [user] [password].

Hosting account passwords are reset in the panel under Accounts → Reset password. That change updates the panel login, SSH, and FTP for that Linux user.

Check and upgrade

Check the public channel, then apply the package. Sites and /var/lib/siroc are kept.

Check for updates
sudo siroc update
Install the latest package
sudo siroc upgrade

Optional arguments:

Custom channel or local tarball
sudo siroc update https://get.siroc.dev
sudo siroc upgrade --url https://get.siroc.dev/siroc-linux-amd64.tar.gz
sudo siroc upgrade --path /var/lib/siroc/updates/siroc-linux-amd64.tar.gz

siroc update runs siroc-agent update. siroc upgrade runs siroc-agent upgrade, replaces siroc-panel and siroc-agent, then restarts the services.

You can also check and apply updates in the panel under System tools → Updates.

Print the installed version:

Version
sudo siroc version

Let's Encrypt

During first-run setup, enter an account email. If Certbot is already installed, Siroc registers the ACME account immediately. Otherwise install Let's Encrypt (Certbot) from Software, then open Websites → Let's Encrypt and click Create Let's Encrypt account.

New sites get a local HTTPS certificate. Issue Let's Encrypt later for public domains. Port 80 must be reachable from the internet for HTTP-01.

Hosting

  • Each hosting account is a Linux user with its own home directory.
  • Nginx sits in front. Sites can be PHP, Node.js, Python, Go, Rust, or Docker.
  • Install Nginx, Apache, PHP, and MySQL or MariaDB from Software before adding sites.
  • The update channel default is https://get.siroc.dev.
